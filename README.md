# Meteora Arena Tool

Аддон для WoW Classic TBC Burning Crusade Anniversary (билд 2.5.5, interface 20505).

Трекает арены: ведёт историю матчей с составами противников, картой,
длительностью, изменением рейтинга и личными заметками. В перспективе
будет подсказывать какие кулдауны сохранять против конкретных композиций.

Парный аддон к **Meteora Raid Tool** — тот же дизайн UI, те же библиотеки,
та же релиз-пайплайна.

## Статус

`v0.1.0` — рабочий скелет:

- Определяет вход/выход арены, тип (2v2 / 3v3 / 5v5 / Skirmish), карту, длительность
- Снимает состав противников через `arena1..arena5` (имена, классы)
- Снимает свой рейтинг до и после боя через `GetArenaTeam`
- Сохраняет матчи в `db.global.matches`
- UI с вкладкой «Лента» — список матчей, цвет результата, изменение рейтинга
- Окно заметок после матча
- Иконка на миникарте, `/mat` slash

В планах (v0.2+): SpecGuess по спеллам, CooldownDB с гибридной базой,
InArenaHUD, sync через AceComm с партнёрами по партии, статистика
винрейтов по сетапам / картам / партнёрам.

## Установка

1. Скачай ZIP релиза с GitHub.
2. Распакуй так, чтобы папка `MeteoraArenaTool` оказалась в `Interface\AddOns\`.

## Слаш-команды

| Команда | Действие |
|---------|----------|
| `/mat` | открыть окно |
| `/mat feed` | перейти к ленте |
| `/mat wipe history` | очистить историю матчей |
| `/mat version` | напечатать версию |
